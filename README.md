# FIAP_GS2026_02_ModelagemLinear_CitizenAssistAI
Projeto de Ciência de Dados desenvolvido em Python, utilizando microdados reais da TIC Domicílios 2024. Aplica análise estatística, testes de hipótese e modelos de regressão linear e logística para identificar perfis de cidadãos e padrões de utilização de serviços públicos digitais.
